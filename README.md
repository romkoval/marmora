# LEVONI — прототип витрины

Статичный прототип главной страницы и каталога изделий из камня. На основном фото в карточке стола или столешницы кнопка **Посмотреть в интерьере** открывает кухню с декором выбранного изделия. Внутри можно менять отделку и перейти к свободному осмотру в 3D.

[Открыть витрину](https://romkoval.github.io/marmora/) · [Стол Staron Glimmer](https://romkoval.github.io/marmora/#/moscow/akril/staron-table) · [Столешница Acrylica «Графит»](https://romkoval.github.io/marmora/#/moscow/akril/acrylica-a205)

Для локального просмотра откройте `index.html` в браузере. Папка `interior/` должна находиться рядом с ним. Геометрия и освещение кухни загружаются при выборе **Осмотр в 3D**.
